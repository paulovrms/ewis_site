# EWIS

Site institucional estático da EWIS. Abra `index.html` no navegador para conferir a página e a simulação. Não é necessário instalar dependências ou compilar.

A demonstração é ilustrativa, sem conexão com equipamentos. O formulário usa a integração Formspree já existente da EWIS.

A raiz contém o `CNAME` de `ewis.com.br`. Antes de publicar, confirme qual branch e pasta o GitHub Pages usa; a configuração de produção não é alterada por esta branch.
